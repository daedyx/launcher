# Sicherheitslücken melden / Reporting a vulnerability

Bitte melde Sicherheitslücken **nicht** als öffentliches Issue, sondern über
„Security → Report a vulnerability“ in diesem Repository (privat).
Please report via “Security → Report a vulnerability” (private), not as a public issue.

Unterstützt wird jeweils nur die neueste veröffentlichte Version.
Only the latest released version is supported.

Wir bestätigen den Eingang innerhalb von 7 Tagen. Kritische Lücken beheben wir
in der Regel innerhalb von 7 Tagen, hohe innerhalb von 30, mittlere innerhalb von 90 Tagen.
We acknowledge reports within 7 days and usually fix critical issues within 7 days,
high within 30 and medium within 90 days.

Dies ist ein kleines, ehrenamtliches Projekt; es gibt kein Bug-Bounty.
This is a small volunteer project; there is no bug bounty.

Bitte schicke keine echten personenbezogenen Daten mit (auch keine echten Mails als Beispiel).
Please do not include real personal data (no real e-mails as examples).
